# Syncraft — portfolio copy

## Title
**Syncraft — Workflow Automation & API Integration Platform**

## Short description
A full-stack automation platform for creating, running and monitoring API-driven workflows with webhooks, scheduled triggers, execution logs and reusable templates.

## Longer description
Syncraft is a modern workflow automation platform built to connect APIs and automate repetitive business processes. Users can build workflows visually, trigger them manually, through webhooks or on a schedule, transform data, call external REST APIs and inspect detailed execution logs.

The project includes JWT authentication, PostgreSQL persistence, an execution engine, workflow templates, integration management, responsive light/dark themes and Docker-based local deployment.
